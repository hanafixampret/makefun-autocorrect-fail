`main.ts` writes one line — a hilarious autocorrect fail — to `/output/entry.txt`:

> Team, the meeting is moved to 3pm. Bring the quarterly reports and your own coffin — I mean COFFEE. Sorry, my phone is out to get me.

The entry is a single line under 200 characters: a mundane work message where autocorrect swaps "coffee" for "coffin", with the sender's panicked in-line correction — the exact shape of a real autocorrect slip.

Run it with Node 22.18+:

```sh
node main.ts
```
